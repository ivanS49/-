# Vibe Browser & Local LLM Engine

A dual-mode Android privacy browser and offline Local LLM assistant.

## Features
- **Dual Mode (Stealth & Browser)**: Separate passcode profiles for browser and offline LLM decoy mode.
- **Offline GGUF LLM Execution**: Powered by `llama.cpp` native integration with mmap & custom context sizing.
- **Privacy & Anti-Fingerprinting**: Resist Fingerprinting (RFP), WebRTC leak blocking, Referer stripping, DNS-over-HTTPS (DoH).
- **Multilingual Localization**: Full support for 7 languages (RU, EN, DE, FR, ES, ZH, AR) with in-app language switching on all screens.
- **Incognito Everywhere**: Universal incognito keyboard enforcement across all input fields.
